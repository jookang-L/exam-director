# 설화고 시험감독표

고등학교 정기시험 감독표를 자동 배정하는 Next.js 14 기반 클라이언트-온리 웹앱입니다.
모든 데이터는 사용자의 **브라우저(IndexedDB)에만** 저장되며 서버로 전송되지 않습니다.

## 핵심 특징

- STEP 0~14 wizard UI (15단계)
- Hard constraint + 배정 우선 규칙 기반 자동 배정 (그리디 + 제한 백트래킹)
- 실시간 검증 — `evaluateAll()`이 자동 배정·수동 수정·사전 검증을 공유
- Undo / Redo, 자물쇠 고정, 부분 재배정
- **STEP 12** — 교사×교시 감독표 (누적 열·정렬·수업 음영), 화면과 동일 구조 **교사별 엑셀**
- **STEP 13** — 감독 균형 힌트: 같은 날짜·교시의 정/부 ↔ 자습 교환 추천
- **STEP 14** — 교사별 감독표 엑셀 **업로드 검증** (외부 수정 후 최종 점검)
- **STEP 15** — PDF (브라우저 인쇄), 일별 고사실표·개인별 통계 **엑셀**, JSON 출력
- 이전 시험 누적피로도 이월

## 기술 스택

- Next.js 14 App Router + TypeScript (strict)
- TailwindCSS + shadcn 스타일 컴포넌트
- Zustand 5 + zundo (Undo/Redo)
- idb (IndexedDB) + localStorage fallback
- exceljs · react-to-print · zod · @dnd-kit

## 감독 수요 자동 생성 (STEP 2 → 3)

시험표·시험 기간을 기준으로 STEP 3 감독 수요를 자동 채웁니다 (`lib/generateDutyDemands.ts`).

| 규칙 | 내용 |
| --- | --- |
| D1 | 시험표에 등록된 **반마다** 해당 고사실에 **정감독 1 + 부감독 1** |
| D2 | 각 학년 **시험 기간 매일 1교시**, 시험 없는 일반반 → **자습감독 1** |
| D3 | 시험 있는 날, **시험 없는 교시·반** → **자습감독 1** (부분 시험 포함) |
| D4 | 자습 자동 대상: **1-1~1-13 / 2-1~2-15 / 3-1~3-13** (특별실 제외) |
| D5 | 복도·특별실 등 **수동 입력값은 유지** (자동 갱신 대상 아님) |

새 시험 생성 시 고사실 목록은 학교 기본값(**55개**: 1학년 13 + 2학년 21 + 3학년 21)이 자동 적용됩니다 (`lib/defaultRooms.ts`).

## 자동 배정 알고리즘 (요약)

### 1단계 — 고정/우선 배정 (`lib/algorithm/fixed.ts`)

아래 순서로 **선배정**합니다. `fixed: true`인 항목은 이후 자동 배정·백트래킹에서 보호됩니다.

| 순위 | 규칙 | 고정 |
| --- | --- | --- |
| 1 | STEP 9 **고정** preassign | ✅ |
| 1 | STEP 9 **우선** preassign | ❌ (슬롯만 선점, 아래 참고) |
| 2 | **C2** — 각 학년 **시험 첫날**(STEP 1 시작일) **1교시** 담임 **자습감독** | ✅ |
| 3 | **C9** — **영양교사** 2교시 부감독 (교사당 연속 2일) | ✅ |

### 2단계 — 그리디 + 백트래킹 (`lib/algorithm/solver.ts`)

1. 남은 슬롯에 대해 `evaluateAll()` 후보 교사 산출
2. 고정 배정 이후 날짜·교시 단위 capacity와 water-filling 목표 누적도를 계산
3. 후보 수가 적은 슬롯부터 **목표 SSD 변화량(deltaSSD)** + **정·부 횟수 균형 패널티**가 낮은 교사 배정
4. 막히면 최대 **50회** 백트래킹 (비고정 배정 swap)
5. **C7 후처리** — 3교시인데 가운데 자습이 없으면 같은 날 **가운데 교시 자습**과 교환 시도
6. **균형 후처리** — fixed·제약·재배정 범위를 유지하며 목표 SSD가 줄어드는 교사 재지정만 반영
7. **다회 실행(선택)** — STEP 11 **균형 강화** 체크 시 고정 seed 8개와 랜덤 seed 4개(중복 제거), 최대 12회 탐색 후 제약 오류→미배정→역할 편차 허용→목표 초과→SSD 순으로 최선 선택. Worker에서 실행해 UI 멈춤 완화.

`totalFatigue = previousFatigueScore × carryOverRatio + currentExamWeight`

**균형 집계 대상** — 평균 누적도와 동일: **강사·영양·평가담당·고사기간 전체 제외** 교사는 C6b·다회 선택 점수에서 제외 (`isIncludedInAverageFatigue`, `lib/algorithm/balanceScore.ts`)

### STEP 11 실행 시

- 솔버에는 기존 배정 중 **`fixed: true`만 입력**하고, 화면의 전체 기존 배정은 별도 baseline 후보로 동일하게 검증·채점
- **Web Worker** (`lib/algorithm/runSolverAsync.ts`)에서 실행 — UI 멈춤 완화
- 완료 후 **정·부 편차**, **누적도 편차**, **목표 초과**, **목표 SSD**, 제약 진단 표시
- 정·부 편차가 허용 범위(각 1회)를 넘으면 경고 배지 표시
- 최종 제약 오류가 있으면 기존 배정을 유지하고 자동 적용하지 않음
- 새 결과가 기존 baseline보다 좋지 않거나 동점이면 기존 배정을 유지
- 완전 배정을 **보장하지 않음** — `미배정 N건`이 남을 수 있으므로 STEP 10·12에서 반드시 확인

## STEP 12 — 교사별 감독표 (`/exam/[id]/review`)

고사실×교시 격자 대신 **교사를 행**, **날짜·교시·감독종류를 열**로 둔 전치(transpose) 그리드입니다 (`lib/grid/teacherDayGrid.ts`, `app/exam/[examId]/review/page.tsx`).

| 구성 | 내용 |
| --- | --- |
| **행** | 교사 (+ 맨 오른쪽 **누적** 열) |
| **열** | 상단 **날짜 탭** → 교시 → 시험과목(학년 칩) → **정 \| 부 \| 자습** |
| **셀** | 배정된 **고사실** (예: `2-4`). 클릭으로 교사 변경 |
| **수동 검증** | 저장 직전에 최신 배정으로 `evaluateAll()` 재검증. 위반 후보는 저장하지 않음 |
| **누적** | `이전피로도×이월 + 현재 감독·수업`. 헤더 클릭 **이름/누적 정렬**, 배정 변경 시 **증가=노랑·감소=초록** 깜빡임 |
| **수업** | STEP 6 시간표 + C5 기준. 감독 없는 교시는 정·부·자습 **병합 1칸**, **쨍한 노랑** 배경에 교실만 표시 |
| **레이아웃** | STEP 12 전용 **전체 너비** (가로 스크롤 최소화) |

**1교시 참고** — 각 학년 시험 첫날 1교시는 시험이 없어 **자습 슬롯만** 생성됩니다(D2). 정·부 열은 빈 칸(회색)으로 보이는 것이 정상입니다.

### STEP 12 엑셀 (`lib/io/teacherGridExcel.ts`)

- 날짜 탭 옆 **「엑셀」** 버튼 → `{시험명}_교사별감독표.xlsx`
- **시트 1개** `교사별감독표` — 화면과 같이 **날짜를 가로로 이어붙임** (요일별 시트 없음)
- 5행 헤더(교사·누적·교시·과목·정|부|자습), 데이터 행 **병합 없음** → 엑셀 **필터·정렬** 가능
- 정규 수업은 정·부·자습 3칸 **노란 음영**, 가운데 교실명

## STEP 13 — 감독 균형 힌트 (`/exam/[id]/balance-hints`)

STEP 12 수동 수정 결과를 기준으로 같은 날짜·교시 안에서 정/부감독과 자습감독을 교환해 정+부 편중을 낮출 수 있는지 점검합니다.

| 항목 | 내용 |
| --- | --- |
| **교환 범위** | 같은 날짜·교시의 `정감독/부감독 ↔ 자습감독`만 추천 |
| **제외 대상** | 강사, 영양교사, STEP 9 우선/고정 배정, 고정된 배정 |
| **검증** | 후보마다 전체 규칙을 다시 검사하며 오류가 있는 후보는 표시하지 않음 |
| **경고** | 오류는 없지만 경고가 있는 후보는 경고 내용과 함께 표시 |

## STEP 14 — 최종 검토 (`/exam/[id]/final-check`)

STEP 12에서 내보낸 교사별 감독표를 **엑셀에서 수정한 뒤** 다시 업로드해 전체 규칙을 점검합니다 (`lib/io/teacherGridExcelImport.ts`).

| 항목 | 내용 |
| --- | --- |
| **입력** | `{시험명}_교사별감독표.xlsx` (시트 `교사별감독표`) |
| **해석** | 교사명·고사실명·날짜·교시·감독종류 열 위치를 STEP 12 내보내기와 동일 레이아웃으로 역변환 |
| **검증** | `runFullValidation()` — C1~C10, 미배정, 업무강도 편차 경고 등 STEP 10·12와 동일 |
| **반영** | 오류 0건일 때만 **배정 반영** 버튼으로 앱 배정 교체 (STEP 15 출력 전 권장) |

**주의** — 열 추가·삭제·날짜 블록 순서 변경 시 잘못 읽을 수 있습니다. 노란 셀(정규 수업)은 감독 배정으로 처리하지 않습니다.

## 역할별 규칙 (STEP 4)

| 역할 | 규칙 |
| --- | --- |
| 정교사 / 기간제 | 일반 제약 적용 |
| **강사** | 자동 배정은 **부감독만** (C4), 하루 **최대 3교시**, 가운데 자습 면제. STEP 12 수동 수정에서는 확인 후 정감독·자습감독 예외 배정 가능 |
| **보건교사** | 같은 교시 **1명만** (C1) |
| **영양교사** | 전체 일정에서 **2교시 부감독**, 교사당 **연속 2일** (C9) |
| **평가담당** | 자동 배정에서 **모든 감독 제외**. STEP 12 수동 배정은 허용 |

### 영양교사 날짜 분배

- 감독 **슬롯이 있는 날짜**를 정렬한 뒤, 명단 **등록 순**으로 2일씩 할당
- 예: 슬롯 날짜 21~25일, 영양교사 A·B → A=21·22일, B=23·24일 2교시 부감독

## C8 과목 매칭

- 기준: STEP 2에 입력된 **모든 시험 과목**. 시험 반 수와 관계없이 해당 과목 교사는 그 날짜·교시의 모든 감독에서 제외
- 예외: STEP 9 **우선/고정**으로 직접 지정한 교사·슬롯은 C8보다 우선
- 교사 **교과**와 시험 **과목** 매칭: 쉼표(`,`)로 복수 교과. **띄어쓰기**와 **숫자 표기**(Ⅰ·I·1, Ⅱ·II·2) 차이는 같은 과목 (`현대사회와 윤리` ↔ `현대사회와윤리`, `미적분Ⅰ` ↔ `미적분1`)
- **다른 이름**(예: `화작`)은 매칭되지 않음 — STEP 2·4에서 동일하게 입력

## STEP 9 우선 vs 고정

| 구분 | 동작 |
| --- | --- |
| **고정** | `fixed: true` — STEP 11 재실행·백트래킹에서 **보호** |
| **우선** | `fixed: false` — 슬롯에 **선배정**되지만 백트래킹 시 **다른 교사로 바뀔 수 있음** |

반드시 지켜야 할 배정은 **고정** 또는 STEP 12 **자물쇠**를 사용하세요.

## 실전 배정 전 체크리스트

1. STEP 2 시험표·STEP 3 「시험표 기준 감독 수요 다시 채우기」
2. STEP 4 역할(강사/보건/영양) 및 **영양교사 명단 순서** 확인
3. STEP 6 시간표, STEP 7 특정 감독 지정/제외
4. STEP 8 슬롯 생성
5. STEP 9 — 필수 배정은 **고정**으로
6. **STEP 10** — 오류 0건 확인 (경고 검토)
7. **STEP 11** — 미배정 0건 확인
8. STEP 12 — 교사별 그리드로 영양·담임·소수과목 확인, 필요 시 자물쇠·**교사별 엑셀** 내보내기
9. **STEP 13** — 감독 균형 힌트 확인 및 필요한 교환 적용
10. **STEP 14** — 엑셀에서 수정했다면 업로드 검증 후 **배정 반영**
11. STEP 15 출력

## 데이터 안전

- IndexedDB 우선, 미지원/실패 시 localStorage로 자동 fallback
- 자동 저장 디바운스 800ms
- JSON export로 다른 컴퓨터·브라우저에 백업/이전 가능

## 알려진 한계

- 자동 배정은 **항상 완전해를 보장하지 않음** (미배정 가능)
- STEP 9 **우선** 배정은 고정이 아니며 백트래킹으로 변경될 수 있음
- STEP 10 공급 부족 검사(`ruleSupplyDemand`)는 강사·영양교사 등 역할 제약 때문에 **실제보다 보수적**일 수 있음 (오탐 가능)
- 영양교사는 제외(C5/C8/EX) 등으로 지정일 배정이 **실패할 수 있음** — STEP 12에서 확인 필요
